# Tier-A Contract Docs Sync (kun-galgame-infra)

This repo is the **single source** for five cross-service contracts: OAuth, image hosting, galgame-wiki, artifact (large files), catalog (cross-media identity registry). Copies in forum/patch repos are banner-stamped mirrors generated by kungal-docs — **never hand-edit downstream copies**; the next sync overwrites them. (`docs/catalog` has no downstream mirror yet — portal + `docs:verify` only.)

## Workflow for a contract change

1. **Code and docs in the same change**: source of truth is the code (`cmd/oauth`, `cmd/image`, `cmd/artifact`, `cmd/catalog` incl. `internal/galgameapp`). When the code changes, update the matching source doc in this repo in the same PR.
2. Edit **only** the source docs here: `docs/integration/oauth`, `docs/image_service`, `docs/integration/galgame_wiki`, `docs/artifact`, `docs/catalog`.
3. Propagate mirrors: `cd ../kungal-docs && pnpm docs:sync --write`.
4. Verify: `pnpm docs:audit` (runs `docs:check` mirror consistency + `docs:verify` source == code) must report **0 errors**.
5. Remember the repo iron rule: commit, but the user pushes (multi-repo push order matters here — state it explicitly).

Docs portal: `docs-kungal.nextmoe.dev`. Ownership model (Tier A/B/C): `../kungal-docs/docs/_meta/ownership.md`.
